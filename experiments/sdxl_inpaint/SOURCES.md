## Local Mac trial preparation

`/Users/emir/Documents/ChatGPT/ArtWorker/.build/dreamlite-venv/bin/python` was inspected through package metadata and source only: Torch 2.14.0, Diffusers 0.39.0, Transformers 4.57.3 and huggingface-hub 0.36.2 are present. The manifest records the actual installed pipeline source SHA256. MFLUX currently has no SDXL inpaint runtime, so this existing Diffusers environment is the straightforward trial path.

[Official Diffusers MPS guidance](https://huggingface.co/docs/diffusers/en/optimization/mps) documents Apple Silicon inference using `.to("mps")`. A future local trial can load this pinned local folder with `variant="fp16"`, `torch_dtype=torch.float16`, `use_safetensors=True`, `local_files_only=True`, then transfer the pipeline to MPS. Use a CPU `torch.Generator` for seeded noise. MPS availability, runtime memory, speed and image quality remain untested here. Attention slicing is a documented memory-pressure option; its benefit with the installed attention processor should be measured.

The installed `StableDiffusionXLInpaintPipeline` code was read directly. It multiplies normalized source RGB by the known-source mask, encodes the masked source, and concatenates mask/source latents into the native nine-channel U-Net input. White mask means regenerate; black means source. Its `get_timesteps` computes `int(20 * 0.99)`, producing **19 Euler timesteps**. CFG uses conditioned/unconditioned branches, so log actual U-Net invocations and evaluated branch batch size instead of reporting requested steps alone. The [upstream pipeline](https://github.com/huggingface/diffusers/blob/8b33bfc04b6b5e8bb58a58e55f68746c1bbee4cd/src/diffusers/pipelines/stable_diffusion_xl/pipeline_stable_diffusion_xl_inpaint.py) documents the same source/mask conditioning and reserves known-latent replacement for the four-channel fallback. Native nine-channel learned conditioning does **not** guarantee exact decoded source pixels. Save the raw reconstruction and a separate composite that pastes the exact original source; do not use the paste as evidence that the model preserved those pixels.

For an outpaint trial, provide the full target-size RGB canvas and same-size binary mask, with the original cover at its exact intended coordinates. This is a practical outpainting use of a trained inpainting model; the official card does not establish dedicated outpainting training, rail continuity, general cover quality, spatial-growth compute savings or iPhone inference performance. Those remain empirical tests.
